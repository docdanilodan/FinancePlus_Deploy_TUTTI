```bash
python -m pytest tests -q -p no:cacheprovider -o faulthandler_timeout=25 --tb=short
```

## Verifica grafica

Build autonoma di 41 pagine a partire dai moduli correnti di presentazione: link interni, asset, etichette e controlli disabilitati verificati. La build funziona senza site-packages e senza accedere al database o al gateway. I frame mobile usano larghezze di 390 e 360 px.

Il primo tentativo di build Render ha scelto Python 3.14 e fallito nell'installazione automatica di psycopg-binary 3.2.9. Il progetto nativo è stato allineato a Python 3.12, coerente con Docker e con il collaudo. Nessuna modifica alle dipendenze finanziarie o al gateway.

La verifica visiva in browser HTTPS e il controllo del rilascio pubblico saranno registrati a conclusione. Nessuna schermata locale bloccata dalla policy del browser è stata trasferita come espediente di navigazione: lo staging esegue una build autonoma dal repository con fixture di esempio.
